Saves

Five slots, all on your computer

Each slot has a name, the in-game date and the time spent on the bench. A career can be exported to a .dsa file to keep aside or move to another computer.

  • The files are in %APPDATA%\talisman\saves, with a button to open the folder.
  • Careers from earlier versions open: the format updates itself.
  • If something goes wrong, "Export diagnostics" creates a file that you decide whether to send.

New in 0.2.1

  • The 2D match rebuilt: highlights, replays, tactical overlays, three cameras.

  • Player instructions and match plans that kick in on their own.

Questions

Download and saves

Is it really free?

Yes. No ads, no in-game purchases, no account. The code is public under the GPL-3.0 licence.

Which languages is it in?

English and Italian. You choose the language at first launch and can change it any time in Settings.

Why does Windows say the publisher is unknown?

Because the installer isn't signed: a code-signing certificate has to be bought, and we haven't got one yet. You can check the file is the right one with the SHA-256 code above.

Does the game send my data anywhere?

No. The game doesn't connect to the internet. Saves and the error log stay on your computer.

Are there real clubs and players?

No: clubs, towns and players are invented. The world format is designed so that, in future, anyone who wants to can load their own data.

Is it a finished version?

It's a version in development: you can play many seasons in a row, but it's the right time to report what's wrong. Known limits are in the release notes.

How do I uninstall it?

From Windows Settings → Apps, like any other program. Saves stay in %APPDATA%\talisman: delete them by hand if you don't need them any more.
