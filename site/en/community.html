Transparent code

Offline

Privacy by default
Data and modding

A world in an open format

The game generates invented clubs, towns and players. The world format is the same one the community database will use: anyone who wants to will be able to load their own leagues. We don't distribute real names and crests — whoever owns them loads them.

01
Export your career

A single file with the whole world, to share or pick up elsewhere.

02
Generated crests

Colours and shapes come from the game: no external images.

03
Migrations

Road travelled, road ahead

Roadmap

The game is built in phases, each one tested before moving on to the next.

Done · 0.1

The complete game and first testing

Match engine and 2D pitch, dressing room, transfers and scouting, stories and press, finances and board, academy and national teams, cup and youth league, Windows installer.

Now · 0.2.0

The match

A rebuilt 2D match, a richer engine, player instructions and match plans, three leagues with play-offs and play-out, clubs that go bust, the game in English.

Next · 1.0

More leagues and the editor

A Linux version, more leagues, an editor for the world and community databases, historical statistics.
