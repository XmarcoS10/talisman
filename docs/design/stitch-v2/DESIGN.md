## Brand & Style

The design system establishes a high-performance football management desktop environment. The visual tone fuses elite European sports broadcast editorial direction with the precision of institutional data cockpits. Designed strictly for deep immersion during tactical orchestration, squad building, and match-day simulations, the aesthetic rejects frivolous sci-fi glows, decorative gradients, and over-stylized neon accents.

Instead, the UI relies on architectural discipline: dense yet scannable information matrices, high-contrast monochrome structural layers, and deliberate micro-moments of intense vermilion velocity. The emotional response is focused, authoritative, strategic, and calm under tactical pressure. 

Every pixel communicates athletic rigor and operational precision. The design style synthesizes modern technical minimalism with sports broadcast typography, emphasizing tabular clarity, strict alignment grids, and immediate legibility under prolonged viewing sessions.

## Colors

The palette is engineered for prolonged visual endurance and zero-glare legibility across 1280x800 and ultra-wide PC displays.

### Foundation Surfaces
- **Canvas Base (`#0F141C`)**: Deep slate charcoal, grounding all match screens and tactical suites.
- **Surface Elevation 1 (`#18202F`)**: Sub-panels, column drawers, contextual navigations, and inactive tabs.
- **Card Container Surface (`#1E293B`)**: Analytical widgets, player detail dossiers, and tactical pitch benches.
- **Structural Outlines (`#2B384E`)**: Crisp 1px structural dividing lines and tabular data borders.

### Accents & Semantic Hierarchy
- **Electric Vermilion (`#FF334B`)**: High-priority broadcast accent reserved exclusively for match continuity actions (e.g., "Confirm Tactics", "Submit Bid", "Advance Day"), live playhead indicators, and crucial urgent notifications.
- **Match Form Semantic Trio**:
  - **Form Win / Positive (`#10B981`)**: Emerald for victory records, green tactical proficiency, and positive budget deltas.
  - **Form Draw / Stasis (`#F59E0B`)**: Amber for draws, conditional contract statuses, and moderate fatigue.
  - **Form Loss / Hazard (`#EF4444`)**: Ruby for defeats, tactical gaps, red cards, and severe squad injuries.

### Neutral Typography Spectrum
- **Text Primary (`#F8FAFC`)**: Pure crisp white for primary headers, tactical labels, and critical metrics.
- **Text Secondary (`#94A3B8`)**: Cool slate for secondary metadata, column descriptors, and contextual notes.
- **Text Disabled / Muted (`#475569`)**: Inactive metrics, historic dead data, and placeholder strings.

## Typography

The typographic hierarchy separates editorial narrative, operational readouts, and quantitative analytics into dedicated type roles:

1. **Broadcast Headlines (`Barlow Condensed`)**: Used strictly in uppercase for section banners, match scoreboards, tactical role badges, and card headers. The condensed proportion maximizes horizontal screen efficiency on multi-column layouts while conveying sports broadcast authority.
2. **Operational Text (`Inter`)**: Neutral, highly legible workhorse used for scout dossiers, tactical instructions, press interactions, and systemic UI labels.
3. **Tabular Telemetry (`JetBrains Mono`)**: Applied to all player attributes, statistical percentiles, squad wages, transfer values, match timers, and tactical coordinates. Numerical values must always render with proportional tabular figures (`font-variant-numeric: tabular-nums`) and standard European decimal formats (e.g., `45,4 Mln €`, `26,6 km/h`).

## Layout & Spacing

The layout model is anchored on a dense 8px/4px base grid optimized for high-density PC displays starting at 1280x800 and scaling dynamically to 2560x1440+.

### Screen Structure
- **Persistent Header (48px high)**: Global calendar ticker, squad summary, active transfer budget, and primary match progression CTA.
- **Fixed Tactical Dock (64px wide, collapsible)**: Left-aligned direct navigation icons for Squad, Tactics, Scouting, Club Operations, and League Tables.
- **Modular Multi-Pane Canvas**: 12-column dynamic fluid grid with `1rem` (16px) gutters. The grid distributes between:
  - *Standard Pitch View*: 7 columns Tactical Board / Pitch Visualization + 5 columns Squad Lineup / Roster attributes.
  - *Data Scout Matrix*: 12 columns full-width responsive tabular matrix with sticky header columns.

### Density Principles
- Content gaps use tight vertical pacing (`space-xs` and `space-sm`) to maximize visible data above the fold without causing visual clutter.
- Component padding scales from `0.5rem` inside compact table cells to `1rem` on analytical dashboard cards.

## Elevation & Depth

Visual hierarchy does not use diffuse blurs, fuzzy shadows, or glowing outlines. Depth is expressed purely through **tonal layering and razor-sharp borders**:

1. **Floor (Base Canvas)**: `#0F141C` handles the global application background and unpopulated gutter sections.
2. **Sub-Containers**: `#18202F` provides baseline structure for major modular regions (e.g., tactics benches, navigation rails).
3. **Active Workspaces / Analytical Cards**: `#1E293B` elevates actionable analytical panels, player cards, and match event tickers.
4. **Structural Delimiters**: A uniform `1px solid #2B384E` border encapsulates all cards, list rows, and modal dialogs.
5. **Interactive Focus**: Hovering interactive items (table rows, squad cards) elevates the fill to `#243247` with no border color change, preserving the spatial grid integrity.
6. **Overlay Modals**: When tactical dialogs or negotiation overlays appear, use a solid backdrop fill of `rgba(15, 20, 28, 0.85)` with a centered modal framed by a `1px solid #FF334B` top highlight border.

## Shapes

The design system employs a disciplined, micro-radius geometry (`roundedness: 1`). 

- Standard inputs, buttons, analytical cards, and data badges utilize `0.25rem` (4px) corner radii.
- Large containers and screen-level overlays employ `0.5rem` (8px) corner radii.
- Circular elements are strictly reserved for player jersey numbers, mini tactical position nodes on the 2D pitch, and circular progress meters.
- Sharp, structural rectangular containers prevent visual softness, reinforcing the industrial, analytical identity of modern club operations.

## Components

### Buttons
- **Primary / Continue CTA**: Filled in `#FF334B` with `#FFFFFF` uppercase `Barlow Condensed` typography (`label-editorial`), height 36px, `0.25rem` radius, horizontal padding `1rem`. Active state: `#E11D48`.
- **Secondary Action**: Background `#18202F`, border `1px solid #2B384E`, text `#F8FAFC`. Hover: Background `#243247`, border `#3B4D6B`.
- **Ghost Action**: Background transparent, text `#94A3B8`, hover text `#F8FAFC`.

### Form Indicators & Tactical Badges (Chips)
- Form badges (W / D / L) render as rigid `20px x 20px` squares with a `0.25rem` radius. 
  - **Win**: `#10B981` background, `#0F141C` text, bold `JetBrains Mono`.
  - **Draw**: `#F59E0B` background, `#0F141C` text.
  - **Loss**: `#EF4444` background, `#FFFFFF` text.
- Tactical role badges (e.g., "B2B", "IF-At", "CD-De") use background `#18202F`, border `1px solid #2B384E`, and `Barlow Condensed` text in `#94A3B8`.

### Data Tables & Roster Lists
- **Header Row**: Height 32px, text uppercase `0.75rem` `Barlow Condensed`, tracking `0.05em`, color `#94A3B8`, background `#141B26`, bottom border `1px solid #2B384E`.
- **Data Rows**: Height 36px, alternating row background between `#1E293B` and `#192333` (zebra striping optional for dense tables). Hover background `#26344A`.
- **Numeric Columns**: Right-aligned, formatted with `JetBrains Mono` with comma separators (e.g., `12,8 km`, `84,2%`, `182.000 €/w`).

### Analytical Pitch Cards
- Outer container: `#1E293B` fill, `1px solid #2B384E` border, `0.25rem` radius.
- Header strip: Height 32px, padding `0 0.75rem`, separated by `1px solid #2B384E`, featuring a condensed uppercase section title and an optional top-right summary metric badge.

### Inputs & Attribute Selectors
- Background `#141B26`, border `1px solid #2B384E`, text `#F8FAFC`, height 32px.
- Focus state: Border transitions to `#FF334B`, outline none.
- Value bars (e.g., player attributes 1–20): High values (16–20) render with `#10B981` fills; intermediate values (11–15) render with `#38BDF8`; lower attributes (1–10) render with `#64748B`.

### Tactical Field Node (Pitch Component)
- 28px circular token with a 2px `#0F141C` stroke.
- Center text: Jersey number or position abbreviation in bold `JetBrains Mono`.
- Condition indicator: Integrated mini pie or crescent progress border showing player stamina (100% Emerald tapering down to Ruby).
